# Images

The `chapters/` directory contains the main illustrations for the textbook. Each
illustration introduces the banking or distributed-systems concept developed in
its corresponding chapter.

Chapter illustration filenames use this convention:

```text
chapter-NN-descriptive-kebab-case-title.png
```

`NN` is the chapter's two-digit number, and the remaining words are a concise
kebab-case description based on the chapter title. There should be exactly one
main illustration for each chapter, referenced immediately below that chapter's
main heading.

Generated diagrams must be manually reviewed before publication. In particular,
check all rendered text for spelling and legibility, and verify that labels,
connections, sequences, amounts, and other diagram details accurately represent
the chapter content.
