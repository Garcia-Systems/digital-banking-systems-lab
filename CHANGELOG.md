# Changelog

## [1.0.0]

### Added

- Institution identity and member-onboarding simulations for Harbor Community Credit Union.
- An authoritative ledger, replay-derived balances, deposits, withdrawals, and atomic internal transfers.
- ACH transfers and returns, settlement records, and reconciliation reports.
- Deterministic queues, worker-capacity comparisons, and the end-to-end banking operations laboratory.

### Reliability

- Bounded retries, duplicate-request demonstrations, and idempotent payment processing.
- Out-of-order event handling and dead-letter isolation without unintended financial effects.

### Documentation

- A completed Chapters 0–18 learning path, canonical CLI reference, roadmap, and release-readiness record.

### Validation

- Host-executable parser completeness, CLI version, default-command, financial-invariant, and repeated-output checks.
- Docker-first CI gates for coverage, package building, Twine validation, release CLI smoke tests, and deterministic capstone output.
